# @dogfishhead drew this elephant.

July 30, 2019 · 1:51 PM UTC

[@dogfishhead](https://www.instagram.com/dogfishhead/) drew this elephant. Think it was a tour guide. It came with the <a href="../../../tags/dfh4life.html">#dfh4life</a> elephant and is without a doubt the highest effort elephant I’ve seen.

It’s a typewritten elephant over a pencil drawing with a Walt Whitman poem. Holding it you immediately think “whoa, save some elephant drawings for the rest of us”. It’s truly amazing.
<a href="../../../tags/funfact.html">#funfact</a> I got this elephant before the Sam Adams merger. If they still had this elephant I’m sure they would have sold for double. <a href="../../../tags/drawmeanelephant.html">#drawmeanelephant</a>
